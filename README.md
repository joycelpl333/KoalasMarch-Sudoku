# KoalasMarch-Sudoku 【Fan Art】
Mascot Sudoku
Mascot Sudoku 是一款為喜愛可愛角色與挑戰腦力的人士設計的網頁數獨遊戲。它不僅僅是簡單的數獨，還結合了精美的角色圖示、深色模式切換與直觀的互動體驗，讓你可以在忙碌的生活中，透過可愛角色的陪伴，享受一段放鬆且刺激的解謎時光。

- 極致的行動端體驗：專為手機螢幕優化，無論是直式或橫式瀏覽，都有精細的排版與手勢操作，隨時隨地皆可開啟挑戰。
- 視覺化數獨：傳統數獨枯燥的數字，在這裡變成了可愛的 Mascot 圖示，大幅提升視覺愉悅感。
- 商業級流暢度：內建音效解鎖機制、自動適應螢幕的 UI 設計，並透過 Web Audio API 模擬出 bubble-like 般的觸感音效，體驗如同原生 App。
- 隱私與效能兼具：遊戲進度無需 LocalStorage，重視隱私且運行輕盈，適合快速開局、快速離線。

你可以用它做什麼？
腦力鍛鍊：透過 4x4、6x6 以及經典的 9x9 三種難度模式，循序漸進地挑戰邏輯極限。
解鎖收藏：完成 10 場 6x6 或 9x9 的遊戲，解鎖專屬的角色驚喜禮物！
自訂偏好：隨時切換深色/淺色模式，並自由選擇喜歡的字體風格，打造屬於你的遊戲介面。

如何使用？
進入遊戲：打開網站後，系統會自動載入資源。

選擇難度：在首頁畫面選擇適合你的模式：
🎯 4x4 Trial Mode：適合初學者，快速熟悉遊戲規則。
🔥 6x6 Mode：中級挑戰，樂趣與難度平衡。
🌟 9x9 Mode：經典挑戰，給想要專注思考的你。

遊玩操作：
點擊格子：選中你要填入數字的格子。
下方數字盤：點擊數字填入，圖示將會顯示在棋盤上。

功能鍵：
↩️ Undo：後悔了？隨時撤銷上一步。
🧹 Erase：擦除填錯的格子。
✏️ Notes：開啟標註模式，記錄可能的候選數字。
🌟 Hint：遇到卡關時，使用提示來突破困境。

追蹤進度：點擊「View Progress」按鈕查看你解鎖神秘獎勵的完成度。
